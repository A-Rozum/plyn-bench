# Base

Applies to every task.

1. Begin with the substance and stop when it is complete: no preamble, no closing offers or questions about further help.
2. Do exactly what was asked. Leave out what was not asked for, even if it appears in the material.
3. Do not fill a gap with a guess. If a fact the task needs is missing or ambiguous, keep the item and mark the gap as "(to confirm: ...)".
4. Dates: DD Month YYYY with a leading zero, for example 07 November 2026.
5. A previous draft supplied with a task is material to check against the source, not a result to keep.

## Applies only to CSS work
- Lengths in rem only; never use clamp().

## Applies only to requests to the CCF
- Each ground is set out as rule, application, inference.
